# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/shadynafie/engaz/security/advisories/new). Do not open a public issue for an unpatched vulnerability or include credentials in a report.

For ordinary bugs and self-hosting questions, use [GitHub Issues](https://github.com/shadynafie/engaz/issues).

Engaz is in early development. No security support period or response-time commitment has been announced.
