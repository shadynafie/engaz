# Data and privacy in self-hosted Engaz

Engaz does not currently offer a hosted service. The person or organisation operating an Engaz server controls its accounts, database, files, backups, and provider connections.

An AI model, memory service, voice service, or connected app may receive task content when it is configured and used. The destination and retention depend on the operator's chosen providers and settings. Review those services before connecting them.

For account or data requests, contact the operator of the server you use. Do not put private data or credentials in public GitHub issues.
